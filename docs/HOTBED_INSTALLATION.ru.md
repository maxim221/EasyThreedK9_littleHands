# Установка Управляемого Hotbed На EasyThreeD K9

Эта заметка фиксирует полевую установку hotbed, сделанную 2026-06-10 для текущего Little Hands K9. Публичный проверенный baseline проекта пока остаётся `LH v5` + внешний warm mat / Cura bed temperature `0`; управляемый hotbed считается экспериментальной веткой до полного print-workflow validation.

## Железо И Подключение

- установленный стол: EasyThreed-compatible heated platform для `X1` / `X2` / `K1` / `K2` / `K7` / `K9`
- товарная ссылка: `https://aliexpress.ru/item/1005012098232684.html`
- в описании товара заявлена максимальная температура hotbed `70C`
- нагреватель стола подключён к board output `Hotbed`
- температурный датчик стола подключён к входу `-TB+`
- соседний вход `-TH+` остаётся датчиком hotend; не переносить туда датчик стола
- измеренное сопротивление датчика стола около комнатной температуры было примерно `10 kOhm`, поэтому stock-like `100k` bed thermistor table не подходит

Практический вывод: если после прошивки холодный `M105` показывает `B:` близко к комнатной температуре и `B@:0`, датчик читается правдоподобно. Если холодный стол внезапно показывает десятки градусов ошибки, нагрев не включать.

## Прошивка

Текущая экспериментальная сборка:

- `firmware/LH-v6-EXP-YZSwap-AutoFan45-FAN1-z600-e1040-watch180-fan253-bed10k-max70-mksLite.bin`
- SHA256: `f547e321e6c1132ad36e6e312bba04c05eedd8b42c4a25525ce6a84a5f93df92`
- firmware identity: `LH v6 EXP YZSwap AutoFan45 FAN1 Z600 E1040 Watch180 Fan253 Bed10K Max70`
- source patch: `docs/firmware/LH-v6-exp-bed10k-max70.patch`

Важные настройки:

- `TEMP_SENSOR_BED 4` (`Generic 10K`)
- `BED_MAXTEMP 70`
- bed preheat presets `50C` / `60C`
- из-за Marlin `BED_OVERSHOOT 10` практический максимум целевой температуры около `60C`

Не ставь цель `70C`: это товарный предел платформы, а не рабочая цель для первого workflow. Для PLA начинать разумно с `45-50C`; `55-60C` проверять только отдельным наблюдаемым тестом.

## Проверенные Тесты Нагрева

Первый тест:

- команда: `M140 S30`
- Marlin `B:` плавно вырос примерно с `22C` до `28C`
- после `M140 S0` выход стола остался `B@:0`
- по инерции Marlin `B:` дошёл почти до `30C`, затем начал снижаться
- внешний датчик оператора в центре стола показал примерно `24C -> 33C -> 31C`

Второй тест:

- команда: `M140 S35`
- Marlin `B:` плавно вырос примерно с `24C` до `34.57C`
- после `M140 S0` выход стола остался `B@:0`
- по инерции Marlin `B:` дошёл почти до `36C`, затем начал снижаться
- внешний датчик оператора показал максимум около `40C` и около `36C` в конце теста

Итог: управление нагревом выглядит живым, но поверхность может быть горячее Marlin `B:` на несколько градусов. До лучшей калибровки держим цели консервативными и продолжаем смотреть внешний датчик.

## Печать С Experimental Hotbed

После первой реальной UF Measure Tool печати края дна слегка поднялись. Для следующего теста это достаточный повод включить стол, но не прыгать сразу к высоким температурам.

Правило для текущего PLA-теста:

- если предыдущая печать легла ровно и края не поднимались, печатай обычный файл без hotbed
- если края дна поднялись, следующий тест печатай с experimental hotbed `35C`
- если `35C` всё ещё не держит углы, следующий отдельный наблюдаемый тест может быть `40C`
- не начинай с `50-60C` для этой детали без новой проверки поверхности и разъёмов

Технически это не Cura bed temperature. Обычная настройка Cura остаётся `0C`, а экспериментальный файл получает явную метку:

```gcode
;LH_EXPERIMENTAL_HOTBED_TARGET:35
M140 S35 ;Experimental controlled hotbed target; Little Hands preheats before M24
```

Little Hands видит эту метку, сам отправляет `M140 S35`, ждёт, пока Marlin `B:` дойдёт примерно до цели, и только потом запускает обычный hotend preheat и `M24`. Блокирующий `M190` в SD-файл не добавлять: если стол/датчик ведут себя странно, ожидание должно сорваться на стороне Little Hands до старта печати, а не застрять внутри SD-потока.

Ручные кнопки `Hotbed 35C`, `Hotbed 40C`, `Hotbed off` остаются для наблюдаемого теста, ручного прогрева и аварийного выключения. Во время активной SD-печати положительные ручные цели заблокированы; `Hotbed off` остаётся доступным как `M140 S0`.

## Выравнивание Стола Щупами

Текущий Cura start workflow объявляет стартовую физическую позу как:

```gcode
G92 X0 Y0 Z0
G1 Z10.0 F600
```

А первый слой профиля уже идёт примерно на `Z0.20`. Поэтому при калибровке нельзя делать большой зазор и считать его `Z0`: если выставить `0.10-0.20 mm` как ноль, реальный первый слой станет слишком высоким.

Цель для этого K9 после установки hotbed:

- основной щуп: `0.05 mm`
- во всех пяти точках Little Hands: `ПЛ` / `Ц` / `ПП` / `ЗЛ` / `ЗП`
- на `Z0` щуп `0.05 mm` должен идти с лёгким, равномерным цеплянием
- щуп `0.10 mm` использовать как верхнюю проверку: он не должен свободно гулять под соплом
- все точки должны ощущаться одинаково; не делай один угол специально выше или ниже

Порядок:

1. Сними пластик со стола и очисти поверхность.
2. Убедись, что сопло чистое, без капли пластика на кончике.
3. Отключи нагрев стола командой `M140 S0`; для первичной механической настройки работай на холодном или слегка тёплом столе.
4. Выставь физический старт, нажми `Save start`, затем переходи кнопками калибровки Little Hands по точкам.
5. В каждой точке опускайся к `Z0` только штатной кнопкой точки, подкладывай `0.05 mm` щуп и регулируй винты/крепление стола до одинакового лёгкого цепляния.
6. Пройди точки минимум два круга: регулировка одного угла меняет соседние.
7. После финального круга снова проверь центр.
8. Перед первой печатью посмотри brim / skirt: линия должна быть непрерывной и слегка приплюснутой, не круглой ниткой поверх стола и не прозрачной протёртой полосой.

Коррекция по первому слою:

- если пластик круглый, плохо липнет или углы сразу поднимаются, зазор всё ещё великоват; уменьшай его маленькими шагами около `0.02 mm`
- если сопло царапает поверхность, пластик не выходит или линия становится слишком прозрачной/рваной, зазор слишком мал; увеличивай его маленькими шагами около `0.02 mm`
- после любой ручной правки стартовой высоты заново нажми `Save start` перед SD-стартом

## Правила Безопасности

- Не включай обычный Cura bed temperature. `M140/M190 S>0` в штатном G-code запрещены; допустим только явно помеченный experimental-hotbed файл без `M190`, с целью не выше `40C`, который Little Hands прогревает перед `M24`.
- Любой новый heat test делай под наблюдением: холодный `M105`, ограниченная цель, контроль роста `B:`, выключение `M140 S0`, проверка `B@:0`.
- Не оставляй принтер без присмотра с включённым hotbed.
- Если есть запах, перегрев разъёма, нестабильный `B:`, пропадает цель или `B@` не уходит в `0` после `M140 S0`, отключай питание и не продолжай тест.
