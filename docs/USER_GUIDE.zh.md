# Little Hands：快速指南

适用于手动保存起点的 EasyThreed K9 / ET-4000+。此工作流没有可靠的限位归零功能，请勿使用 G28。

## 1. 连接并保存起点

1. 连接 USB，选择打印机端口，或点击“查找”。
2. 设置实际起点：打印头在左侧，平台远离操作者，喷嘴位于平台表面。观察各轴运动，避免撞到机械尽头。
3. 点击“保存起点”。此按钮将当前位置声明为零点，不移动各轴。

X 控制打印头左右；Y 控制平台靠近/远离；Z 控制打印头上下。点动步长为 0.1–50 mm。打印机确认指令不代表机械实际移动；若轴未移动，请检查机械并重新设置起点。

## 2. 准备并打印

1. 在 Cura 中选择 lilHands K9 warm mat 和谨慎的 K9 配置，将 G-code 保存到项目的 gcode/。在 Preview 中检查模型方向；未经检查不要直接切片原始 moduleBot.STL。
2. 打开“文件和固件”，选择 G-code，点击“检查 G-code”，再使用“上传 G-code”或“上传并启动”。
3. 已上传的文件可从 SD 列表选择，再点击“开始打印”。打印机必须实际位于已保存起点。
4. 等待预热：文件要求热床时先加热平台，然后按 60/100/150/200°C 分段加热喷嘴，并完成最后的温度等待。喷嘴预热前会升高 10 mm，启动前再返回起点。
5. 启动后的前 180 秒 USB 可能没有回复。请目视观察；USB 沉默本身不代表打印停止。此时不要刷新 SD 列表。

取消或损坏的上传文件会被禁止启动，直到删除或重新上传并验证成功。不要直接从卡上启动未知的残缺文件。操作期间禁止更换端口或关闭应用；上传可用“取消”停止。

## 3. 加热与耗材

- 公开 LH v5 固件使用外部加热垫。已安装的受控热床需要 LH v6 Bed10K Max70。
- 新本地切片通过 ;LH_EXPERIMENTAL_HOTBED_TARGET:60 和 M140 S60 请求 60°C。Cura 普通热床温度保持 0°C，SD 文件不得使用 M190。旧文件需要重新切片并上传才会改变目标温度。
- 手动热床按钮为 35/40/50/55/60°C 和“关闭 hotbed”。目标上限为 60°C。打印前最多等待 15 分钟，同时确认实际温度和接受的设定值。预热失败时会尝试关闭两个加热器，并禁止启动打印。
- SD 打印期间禁止手动开启热床；USB 操作之间可使用“关闭 hotbed”。
- “Hotend 200C”用于手动装载耗材。确认温度达到 180°C 后，选择 E 步长，再点击“进料”或“回抽”。打印期间禁止这些动作。“关闭 hotend”停止喷嘴加热。

60°C 是操作者选择的目标，修改设置不等于完成物理验证。新测试前先检查冷态 B: 合理且 B@:0，观察升温，最后关闭热床。如有异味、接头发热、读数不稳定或无法关闭加热，请切断电源。喷嘴正常预热初期曾出现轻微咔哒声，仅凭此现象无需修改固件。

## 4. 结束、停止与返回

1. 确认打印结束并取下模型。
2. 在手动控制中点击“回到保存起点”。只有满足对话框中的全部条件才能确认恢复。
3. 下次打印前关闭打印机电源 5–10 秒，再上电，检查实际起点并再次点击“保存起点”。下一次启动时确认已完成该断电流程。

“暂停”和“继续”控制 SD 打印。普通“停止”保存恢复位置，尝试安全抬起喷嘴，并停止打印和加热。“紧急停止”用于紧急情况；遇到直接危险应切断打印机电源。“关闭电机”会使起点失去可信状态。

USB 断开或应用重启后不会自动返回各轴。根据保存的最终位置恢复，必须确认打印结束、模型已取下且各轴未被移动。若只有一个安全的打印机端口可用，应用可以重新选择该端口。

如果抬起喷嘴后预热失败，不要把抬高的位置保存为起点。应用先尝试撤销已知的抬升；若失败，请恢复 USB，点击“回到保存起点”，并确认打印未启动且各轴未移动。出现 Heating failed 时必须先断电重启。卡住的轴应先检查机械，不要通过提高速度强行移动。

## 5. 调平

保存起点后可使用五个调平点：前左 / 中 / 前右 / 后左 / 后右。在 Z0 使用 0.05 mm 塞尺，以轻微且一致的阻力为准。0.10 mm 仅作上限检查，不是目标间隙：Cura 首层本身已经升到约 Z0.20。调整后再次保存起点，并目视检查首层。

## 6. 帮助与文件

“说明”随所选语言切换。“导出 Cura 配置”将本地设置保存到 exports/。修改 Cura 设置时请关闭 Cura；打印机空闲时再重启 Little Hands。不要让 Cura 控制打印机唯一的风扇。

“USB 指标”显示固件回复，“保存日志”保存诊断信息。日志和状态位于项目内的 monitor_logs/。请使用适合主板的固件；实验版本不会自动替代公开 LH v5 基线。
