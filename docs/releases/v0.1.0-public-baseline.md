# Little Hands v0.1.0 - K9 Public Baseline

This is the first conservative public baseline for Little Hands on EasyThreeD K9 / ET4000+ printers.

## What This Release Is

Little Hands is a Linux desktop control center for a small K9 workflow that does not rely on normal endstop-based `G28`. It helps an operator print from the printer SD card while keeping the manual-zero start and recovery path explicit.

Validated public baseline:

- printer family: `EasyThreeD K9`
- board family: `ET4000+ / ET4000PLUS`
- app: `tools/k9_control_center.py`
- firmware: `firmware/LH-v5-YZSwap-AutoFan45-FAN1-z600-e1040-watch180-mksLite.bin`
- Cura machine/profile: `lilHands K9 warm mat` / `codex - K9 warm mat cautious`
- host: Linux desktop or Raspberry Pi OS Desktop

## Highlights

- SD print start/stop/status workflow
- USB G-code upload to printer SD
- firmware upload helper
- manual-zero `Save start` workflow using `G92 X0 Y0 Z0`
- guarded `Go to saved start` recovery after prints/stops
- staged hotend preheat before SD start
- G-code safety validation before upload/start
- conservative Cura profile and manual slicer settings
- manual movement and bed-leveling point buttons gated by trusted start
- USB metrics capture for `M115`, `M503`, `M114`, `M105`, and `M27`
- RU / EN / ZH documentation and UI language support

## Important Safety Notes

- Do not add startup `G28`.
- Do not use this as a generic K9 firmware package without checking your board and wiring.
- Do not enable Cura bed heat for the public baseline; bed target stays `0C`.
- Do not add `M18` / `M84` at the end of print files.
- If a start fails with no heat/no motion, power-cycle the printer, re-check physical start, and press `Save start` again.
- If USB telemetry is quiet but the printer is physically heating, moving, or printing, do not power-cycle just because the app is waiting.

## Experimental Hotbed Note
